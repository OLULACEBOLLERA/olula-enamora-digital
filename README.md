# Olula Enamora Digital

Quiero que actúes como director creativo, diseñador UX/UI, desarrollador frontend y auditor de contenido especializado en webs culturales y eventos municipales.

Ya existe un borrador funcional de la web de la Feria y Fiestas de Olula del Río 2026. Antes de modificar nada, analiza minuciosamente el proyecto actual y compáralo con el contenido y diseño del Libro Oficial de la Feria y Fiestas de Olula del Río 2026 que te he proporcionado.

1. NO EMPIECES DE CERO

Esta instrucción es MUY IMPORTANTE.

No quiero que sustituyas la web actual por una plantilla genérica ni que hagas una web completamente nueva.

Quiero que:

Analices primero toda la web existente.

Identifiques qué elementos están bien y deben conservarse.

Detectes qué información, imágenes, secciones, funcionalidades o contenidos faltan.

Detectes errores de diseño, estructura, textos, enlaces, teléfonos, direcciones o nombres.

Mejores progresivamente el proyecto existente.

Conserves todo lo que sea útil y correcto.

Solo sustituyas elementos cuando exista una alternativa claramente mejor y coherente con el proyecto.

Antes de realizar cambios, crea mentalmente una lista de:

Lo que ya existe y funciona.

Lo que falta.

Lo que debe corregirse.

Lo que debe rediseñarse.

Lo que debe comprobarse con el libro oficial.

No elimines contenido simplemente porque no sepas cómo utilizarlo.

La web debe parecer una reinterpretación digital del libro, no un PDF convertido en HTML.
